# AI Resume Screening & Job Recommendation System

An AI-powered web application designed to analyze resumes and help candidates discover job opportunities relevant to their skills and experience.

## Live Demo

🚀 **Try the Application:** https://ai-resume-screening-job-recommendation-ff6anaqhh8kqkynzndonwf.streamlit.app/)

💻 **GitHub Repository:** [(https://github.com/khushbookmt/AI-resume-screening-job-recommendation)

## Overview

Finding suitable job opportunities and understanding how well a resume aligns with a job description can be challenging. This project explores how Artificial Intelligence and Natural Language Processing can support resume analysis and job matching.

The application provides a web interface for processing resumes and exploring relevant job recommendations.

## Key Features

- Resume upload and analysis
- Resume-to-job matching
- Job recommendations based on available resume information
- Skills and keyword analysis, where supported by the implementation
- Interactive web interface built with Streamlit

*Feature descriptions should reflect what the current application actually does.*

## Technology Stack

- **Language:** Python
- **Web Framework:** Streamlit
- **Domain:** Artificial Intelligence, Natural Language Processing, and Machine Learning

Additional libraries and algorithms are documented according to the actual implementation.

## How It Works

1. The user uploads a resume.
2. The application extracts and processes available resume information.
3. The system analyzes the resume using its implemented matching approach.
4. Relevant job results are presented through the interface.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/khushbookmt/AI-resume-screening-job-recommendation.git
cd AI-resume-screening-job-recommendation
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
streamlit run app.py
```
